# DSA Using Python

A collection of beginner-friendly data structures and algorithms implemented in
Python. Each file is a small, standalone example with sample input and output,
so it can be read and run independently.

## Topics Covered

| Directory | What it contains |
| --- | --- |
| [Array Basics](Array%20Basics) | Average, sums, minimum and maximum values, even/odd checks, reversing, rotation, duplicate removal, and the second-largest element |
| [Array Medium](Array%20Medium) | Kadane's algorithm, product of array except self, and a two-sum example |
| [Linked List](Linked%20List) | A singly linked list with insertion, deletion, and display operations |
| [Queue](Queue) | A basic queue, circular queue, and deque implementations |
| [Search Algorithm](Search%20Algorithm) | Linear search and binary search |
| [Sorting Algorithm](Sorting%20Algorithm) | Bubble, insertion, selection, merge, and quick sort |
| [Leetcode](Leetcode) | Practice solutions for palindrome, stock profit, parentheses, square root, two-sum, median, and other common problems |

## Getting Started

Requirements:

- Python 3.8 or newer
- No third-party packages

Run an example from the repository root:

```powershell
python ".\Search Algorithm\Binary_search.py"
python ".\Sorting Algorithm\Quick_Sort.py"
python ".\Queue\Queue.py"
```

On macOS or Linux, use forward slashes and `python3`, for example:

```bash
python3 "Search Algorithm/Binary_search.py"
```

## Suggested Learning Path

1. Begin with [Array Basics](Array%20Basics).
2. Practice [searching](Search%20Algorithm) and [sorting](Sorting%20Algorithm).
3. Study the [linked list](Linked%20List) and [queue](Queue) implementations.
4. Try the problems in [Array Medium](Array%20Medium) and [Leetcode](Leetcode).

## Notes

- Examples use simple variables and loops to keep the underlying idea visible.
- Many files execute their demonstration code immediately when run.
- Some implementations are intentionally introductory and can be extended with
	input validation, reusable functions, type hints, and automated tests.
